I work on open problems posed by Paul Erdős, as collected at [erdosproblems.com](https://www.erdosproblems.com), mostly by computing values that had not been published before and sharing the programs so anyone can check them.

### Credited in the OEIS

The [On-Line Encyclopedia of Integer Sequences](https://oeis.org) credits me in four entries ([all four in one search](https://oeis.org/search?q=%22Leandre+Jack%22)):

- [A388850](https://oeis.org/A388850), Erdős problem 382: the terms a(9) to a(13), and a(15)
- [A375071](https://oeis.org/A375071), Erdős problem 389: the terms a(27) and a(28)
- [A392164](https://oeis.org/A392164), Erdős problem 1109: the table of values up to n = 3000 (the entry had them up to n = 700)
- [A392165](https://oeis.org/A392165), Erdős problem 1109: the terms a(40) to a(65)

### Lean formalisations

Three of my contributions are part of Google DeepMind's [formal-conjectures](https://github.com/google-deepmind/formal-conjectures) project, which lists me in its [AUTHORS](https://github.com/google-deepmind/formal-conjectures/blob/main/AUTHORS) file:

- Erdős problem 430, added to the project ([#5261](https://github.com/google-deepmind/formal-conjectures/pull/5261))
- Corrected statements of Erdős problems 11 ([#6650](https://github.com/google-deepmind/formal-conjectures/pull/6650)) and 873 ([#6651](https://github.com/google-deepmind/formal-conjectures/pull/6651))

### Programs

The programs, logs and checks behind each result are in [erdos-computations](https://github.com/leandrejack-afk/erdos-computations). I use a large language model to help write and check them.
